# Cómo publicarlo gratis
1. Crea una cuenta en https://github.com
2. Crea un repositorio público.
3. Sube estos archivos.
4. En Settings > Pages selecciona Deploy from branch.
5. El enlace generado conviértelo en un código QR usando cualquier generador de QR.
También puedes arrastrar esta carpeta a Netlify Drop: https://app.netlify.com/drop
