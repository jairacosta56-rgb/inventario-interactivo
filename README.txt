# 📸 Sistema de Auditoría de Inventario Fotográfico

## Evaluación Final - POA

Aplicación web desarrollada como solución al **Problema 3 – Auditoría de Inventario**, correspondiente a la Evaluación Final POA.

El sistema permite registrar el inventario de equipos fotográficos, clasificar el estado de cada artículo y generar un reporte de reabastecimiento de forma automática.

---

## Características

- Registro de existencias del inventario.
- Validación de datos ingresados.
- Clasificación automática del inventario:
  - 🟢 SUFICIENTE
  - 🟡 BAJO
  - 🔴 CRÍTICO
- Cálculo automático de las unidades que deben solicitarse.
- Reporte general del inventario.
- Reporte de artículos que requieren reabastecimiento.
- Interfaz web adaptable a computadores y dispositivos móviles.

---

## Tecnologías utilizadas

## Artículos evaluados

- Cámara fotográfica Nikon
- Cámara fotográfica Sony
- Lente 80 mm
- Flash
- Memoria SD
- Disco duro SSD
- Trípode

---

## Cómo ejecutar el proyecto

1. Descargar el repositorio.
2. Abrir el archivo **index.html** con cualquier navegador web.
3. Ingresar las cantidades disponibles.
4. Pulsar **Generar Reporte**.

No requiere instalación de programas adicionales.
